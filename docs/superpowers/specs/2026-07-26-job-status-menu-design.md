# 공고 상태 변경 메뉴 설계

## 목표

공고 관리 행의 더보기 버튼이 상태를 즉시 바꾸지 않고, 사용자가 의도를 확인할 수 있는 명시적 메뉴를 제공한다.

## 범위

- 더보기 버튼을 드롭다운 메뉴 트리거로 바꾼다.
- 모집중 공고에는 `공고 마감`, 마감 공고에는 `모집 재개` 메뉴 항목을 표시한다.
- 메뉴 항목을 선택할 때만 기존 로컬 상태를 변경하고 성공 토스트를 표시한다.
- 확인 모달, API 호출, 공고 삭제 기능은 추가하지 않는다.

## 동작

1. 더보기 버튼을 누르면 버튼 아래에 상태 변경 메뉴가 열린다.
2. 메뉴에는 현재 상태의 반대 액션 하나만 보인다.
3. 해당 액션을 누르면 공고 상태가 변경되고 `공고를 마감했습니다` 또는 `모집을 재개했습니다` 토스트를 표시한다.

## 검증

- 더보기 버튼만 눌렀을 때 상태가 바뀌지 않는지 확인한다.
- 모집중·마감 공고에서 각각 올바른 메뉴 라벨과 변경 토스트를 확인한다.
- 전체 build, lint, FSD 검사, 타입 검사를 실행한다.
