# 프로필 첨부 파일 UI 설계

## 목표

학생 프로필에서 이력서·포트폴리오 등 PDF 파일을 계정당 최대 3개까지 브라우저 상태로 관리한다.

## 범위

- 기존 이력서 카드를 `첨부 파일` 카드로 바꾼다.
- 초기 이력서 목업 파일을 포함해 파일명 목록을 표시한다.
- PDF 파일을 한 번에 하나씩 추가하고, 각 항목을 개별 삭제한다.
- 파일이 3개면 추가를 비활성화하고 최대 개수 안내를 표시한다.
- 파일 종류 구분, 실제 업로드 API, 새로고침 후 상태 유지, 드래그 앤 드롭은 포함하지 않는다.

## 구성과 상태

- `ProfileView`가 파일명 목록을 로컬 상태로 소유한다.
- 기존 단일 이력서 교체 feature는 범용 파일 추가 입력으로 대체한다.
- 추가 입력은 PDF만 허용하며 선택한 파일명을 부모에 전달한다.
- 최대 개수 검사는 `ProfileView`에서 수행해 입력을 비활성화한다.

## 동작

1. 초기 목록에는 `김도윤_2314_이력서.pdf`가 있다.
2. 사용자가 PDF 하나를 선택하면 목록 끝에 파일명이 추가되고 성공 토스트를 표시한다.
3. 사용자가 삭제를 누르면 해당 항목을 목록에서 제거하고 성공 토스트를 표시한다.
4. 목록이 3개면 추가 입력을 사용할 수 없고 `최대 3개까지 등록할 수 있습니다`를 표시한다.

## 검증

- 파일 추가·삭제와 3개 제한을 검사하는 작은 테스트를 먼저 작성한다.
- 전체 build, lint, FSD 검사, 타입 검사를 실행한다.
