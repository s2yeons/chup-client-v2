# 어드민 공고 등록 폼 설계

## 목표

어드민이 여러 모집 포지션, 마감일, PDF 첨부파일을 포함한 채용 공고를 로컬 상태로 등록하고 지원자 목록에서 전화번호를 확인할 수 있게 한다.

## 범위

- 공고 등록 폼에 `shadcn` `Date Picker` 기반 마감일 선택을 추가한다.
- 기본 포지션을 다중 선택하고 직접 입력한 포지션도 추가·삭제할 수 있게 한다.
- PDF 파일을 최대 3개까지 추가·삭제하고, 등록된 공고에 파일명만 보관한다.
- 지원자 관리 테이블에 전화번호 컬럼을 추가한다.
- 실제 파일 업로드, 공고 등록 API, 새로고침 후 첨부파일 유지, 첨부파일 목록 표시는 포함하지 않는다.

## 구성과 상태

- `@chup/ui`에 `Calendar`와 `Popover`를 추가해 공통 `Date Picker` UI를 구성한다.
- `PostingsView`는 선택한 포지션, 직접 입력 중인 포지션, 마감일, 첨부파일을 로컬 상태로 소유한다.
- 기본 포지션은 `프론트엔드`, `백엔드`, `DevOps`, `AI`, `클라우드`다.
- 첨부파일은 `File` 객체로 검증하고, 공고 상태에는 파일명 배열만 보관한다.
- `JobType`에 첨부파일 파일명 배열을 추가한다.

## 동작

1. 기본 포지션 칩을 누르면 선택 또는 해제된다.
2. 직접 입력한 포지션은 추가 후 선택된 칩으로 표시되며, 중복 값은 추가하지 않는다.
3. `Date Picker`에서 마감일을 선택하면 등록 폼에 표시되고, 공고 목록에는 `YYYY.MM.DD` 형식으로 보인다.
4. PDF만 한 번에 하나씩 추가할 수 있고, 최대 3개까지 각 파일을 삭제할 수 있다.
5. 회사명, 포지션 1개 이상, 마감일이 모두 있어야 등록할 수 있다.
6. 등록 시 선택된 포지션·마감일·첨부파일 파일명이 새 공고의 로컬 상태에 저장된다.
7. 지원자 목록은 기존 이름·학번·이메일 정보와 별도로 전화번호를 표시한다.

## 검증

- 포지션 다중 선택, 직접 추가, 중복 방지를 확인한다.
- 마감일 미선택, PDF 이외 파일, 파일 3개 초과 시 토스트를 확인한다.
- 등록된 공고의 포지션과 마감일 표시를 확인한다.
- 지원자 목록의 전화번호 컬럼을 확인한다.
- 전체 build, lint, FSD 검사, 타입 검사를 실행한다.
