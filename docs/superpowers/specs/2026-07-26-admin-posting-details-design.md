# 어드민 공고 상세 정보 입력 설계

## 목표

어드민이 공고 등록 시 고용 형태와 회사 소개를 입력하고, 학생 공고 상세 화면에서 등록한 첨부파일 파일명을 확인할 수 있게 한다.

## 범위

- 공고 등록 폼에 고용 형태 선택 UI를 추가한다.
- 공고 등록 폼에 회사 소개 텍스트 입력을 추가한다.
- 공고 상세 화면에서 공고에 저장된 첨부파일 파일명을 목록으로 표시한다.
- 실제 파일 업로드·다운로드 API, 회사 로고 업로드, 별도 공고 제목 입력은 포함하지 않는다.

## 구성과 상태

- 고용 형태는 `정규직`, `산업기능요원`, `인턴`, `계약직` 중 하나를 선택한다.
- 회사 소개는 `PostingsView`의 로컬 상태로 입력받아 기존 `JobType.description`에 저장한다.
- 첨부파일은 기존 `JobType.attachments`의 파일명 배열을 사용한다.
- 공고 제목은 기존처럼 모집 포지션에서 만들고, 회사 이니셜과 D-day는 회사명·마감일에서 만든다.

## 동작

1. 새 공고 등록 시 회사명·고용 형태·회사 소개·포지션 1개 이상·마감일을 모두 입력해야 한다.
2. 등록 후 목록에는 선택한 고용 형태가 표시되고, 상세 화면에는 회사 소개가 표시된다.
3. 상세 화면의 첨부파일 영역에는 등록한 파일명을 각각 표시하고 다운로드 토스트를 제공한다.
4. 첨부파일이 없으면 첨부파일 영역을 표시하지 않는다.

## 검증

- 고용 형태와 회사 소개 누락 시 오류 토스트를 확인한다.
- 새 공고의 목록 고용 형태·상세 회사 소개·첨부파일 파일명 표시를 확인한다.
- 전체 build, lint, FSD 검사, 타입 검사를 실행한다.
